# Installing the apps

Open the app's address and sign in. Admin: `https://admin.greenscapelandscapingph.com`. Employee: `https://employee.greenscapelandscapingph.com`. Both can be installed on the same device.

## Android (Chrome, Edge, Samsung Internet)

1. Employee: Profile → **Install the app** → **Install app**. Admin: account menu → Settings → **Install the app** → **Install app**.
2. Confirm in the browser's dialog.

If the button is not shown, use the browser menu (⋮) → **Install app** or **Add to Home screen**. Firefox for Android offers **Add to Home screen** in its menu.

## iPhone and iPad

1. Open the address in **Safari** (iOS 16.4 and later also allow Chrome and Edge).
2. Tap **Share**.
3. Choose **Add to Home Screen**, then **Add**.

iOS has no install button for websites; the app shows these steps instead. Alerts (push) on iOS only work after the app was added to the Home Screen, and only on iOS 16.4 or later.

## Computer

- **Chrome, Edge**: the Install button in Settings / Profile, or the install icon in the address bar.
- **Safari (macOS 14+)**: File → **Add to Dock**.
- **Firefox**: cannot install websites. The site works the same in a tab.

## What the app tells you

| State | Shown |
|---|---|
| Browser offered installation | "Install app" button |
| Opened as an installed app | "You are using the installed … app." |
| Just installed | "… was installed. Open it from your home screen or app list." |
| Offer declined | "Not installed. You can do it later: …" (no repeated prompts) |
| iPhone / iPad | The three Safari steps |
| Anything else | Where to look in the browser's menu |

The app never asks by itself. Chrome's own install banner is suppressed; the only prompt is the one behind the button.

## Removing

Android / iOS: long-press the icon → Uninstall / Remove App. Desktop Chrome / Edge: open the app → ⋮ → Uninstall.
